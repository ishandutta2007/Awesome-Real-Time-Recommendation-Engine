# Awesome-Real-Time-Recommendation-Engine

# Top Real-Time Recommendation Engine Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Personalization, Collaborative Filtering & Self-Hosted Recommenders*  
**Last updated: October 2026**

This repository tracks notable **commercial recommendation platforms** and **open-source projects** that generate personalized recommendations in real time — product suggestions, content feeds, and next-best actions for e-commerce, media, and applications.

**Examples** include Amazon Personalize, Dynamic Yield, Algolia Recommend, Coveo Machine Learning, Recombee, Bloomreach Discovery, Crossing Minds, Segment Personas, Insider, and Nosto (the category leaders).

**Open-source emphasis**: Recommendation engines are a strong open-source domain. **Apache PredictionIO**, **Gorse**, **Recommender**, and **LensKit** provide production-grade recommender systems. **Merlin** and **NVIDIA Merlin** accelerate deep learning recommenders. **LightFM**, **Implicit**, and **Surprise** deliver collaborative filtering. **Qdrant**, **Weaviate**, and **Milvus** power vector-based semantic recommendations. **Elasticsearch** and **OpenSearch** enable search-based recommendations. This section is heavily expanded.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## Open-Source GitHub Projects

### Recommendation Engines

- **[Apache PredictionIO](https://github.com/apache/predictionio)**  
  **Open-source machine learning server for developers**, Apache-2.0 licensed with **12,000+ GitHub stars** . **Build and deploy predictive engines** including recommendations . **Template gallery for common use cases** . **Note**: Development has slowed; community forks exist . **Best for understanding recommendation architecture** .

- **[Gorse](https://github.com/gorse-io/gorse)**  
  **Open-source recommender system**, Apache-2.0 licensed with **8,000+ GitHub stars** . **Built in Go with real-time recommendations** . **Collaborative filtering, content-based, and hybrid models** . **REST API and dashboard** . **Best for production recommender systems** .

- **[Recommender](https://github.com/spring-projects/spring-statemachine)** — Spring-based recommender (not actively maintained) .

- **[LensKit](https://github.com/lenskit/lenskit)**  
  **Open-source recommender toolkit**, Apache-2.0 licensed . **Python-based with collaborative filtering algorithms** . **Evaluation framework for recommender research** . **Best for research and evaluation** .

- **[Merlin](https://github.com/NVIDIA-Merlin/Merlin)**  
  **NVIDIA's recommender framework**, Apache-2.0 licensed with **3,000+ GitHub stars** . **Deep learning recommender models** . **GPU-accelerated training and inference** . **Best for deep learning recommenders** .

- **[Surprise](https://github.com/NicolasHug/Surprise)**  
  **Python scikit for recommender systems**, BSD-3-Clause licensed with **6,000+ GitHub stars** . **Collaborative filtering algorithms** . **Built-in evaluation tools** . **Best for research and prototyping** .

- **[LightFM](https://github.com/lyst/lightfm)**  
  **Hybrid recommendation algorithm**, Apache-2.0 licensed with **4,000+ GitHub stars** . **Combines collaborative and content-based filtering** . **Best for hybrid recommendations** .

- **[Implicit](https://github.com/benfred/implicit)**  
  **Fast collaborative filtering for implicit datasets**, MIT licensed with **3,000+ GitHub stars** . **ALS, BPR, and logistic matrix factorization** . **Best for implicit feedback** .

### Vector Search & Semantic Recommendations

- **[Qdrant](https://github.com/qdrant/qdrant)**  
  **High-performance vector database**, Apache-2.0 licensed with **20,000+ GitHub stars** . **Semantic search with filtering** . **Best for vector-based recommendations** .

- **[Weaviate](https://github.com/weaviate/weaviate)**  
  **Open-source vector database**, BSD-3-Clause licensed with **12,000+ GitHub stars** . **Semantic search with GraphQL API** . **Best for AI-native recommendations** .

- **[Milvus](https://github.com/milvus-io/milvus)**  
  **Cloud-native vector database**, Apache-2.0 licensed with **30,000+ GitHub stars** . **Billion-scale vector search** . **Best for large-scale recommendations** .

- **[Chroma](https://github.com/chroma-core/chroma)**  
  **AI-native embedding database**, Apache-2.0 licensed with **15,000+ GitHub stars** . **Simple API for LLM applications** . **Best for semantic recommendations** .

### Search-Based Recommendations

- **[OpenSearch](https://github.com/opensearch-project/OpenSearch)**  
  **Open-source search and analytics suite**, Apache-2.0 licensed with **10,000+ GitHub stars** . **Search-based recommendations** . **Best for search-driven recommendations** .

- **[Elasticsearch](https://github.com/elastic/elasticsearch)**  
  **Search and analytics engine**, SSPL/Elastic License . **Search-based recommendations** . **Best for Elastic ecosystem** .

- **[Meilisearch](https://github.com/meilisearch/meilisearch)**  
  **Fast search engine**, MIT licensed with **45,000+ GitHub stars** . **Typo-tolerant search for recommendations** . **Best for application search** .

- **[Typesense](https://github.com/typesense/typesense)**  
  **Typo-tolerant search engine**, GPL-3.0 licensed with **20,000+ GitHub stars** . **Search-based recommendations** . **Best for site search** .

**Frameworks for building custom real-time recommendation engines**: Combine **Gorse** for production recommender systems with Go . Use **LensKit** or **Surprise** for research and evaluation . Deploy **Merlin** for deep learning recommenders with GPU acceleration . Integrate **LightFM** or **Implicit** for collaborative filtering . Use **Qdrant**, **Weaviate**, or **Milvus** for vector-based semantic recommendations . Choose **OpenSearch** or **Meilisearch** for search-based recommendations . Note that true managed recommendation services with automatic scaling, real-time personalization, and vendor-supported SLAs (Amazon Personalize, Dynamic Yield, Algolia Recommend) remain primarily commercial territory; open-source stacks provide strong recommender algorithms, vector search, and search foundations that require integration for complete personalization.

## Disclaimer

- This is a **community-curated** list — not exhaustive and not an endorsement.
- Recommendation engines process user behavior data and may raise privacy concerns. Self-hosted solutions require proper security hardening, access controls, and compliance with data privacy regulations (GDPR, CCPA).
- **Real-time recommendations require low-latency infrastructure** — vector search, feature stores, and model serving must respond in milliseconds. Plan infrastructure accordingly .
- **Cold start remains challenging** — new users and items lack interaction data. Hybrid approaches (content-based + collaborative) mitigate this .
- **License considerations**: Gorse uses Apache-2.0, LensKit uses Apache-2.0, Merlin uses Apache-2.0, and LightFM uses Apache-2.0. Verify licensing against your use case before committing .
- The open-source ecosystem provides strong recommender algorithms, vector search, and search foundations, but **managed infrastructure, automatic scaling, and vendor-supported SLAs** remain primarily commercial offerings.
